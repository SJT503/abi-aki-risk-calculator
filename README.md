# abi-aki-risk-calculator

## Paper 2: JinhuaNSICU development with MIMIC-IV and eICU-CRD external validation

Rolling prediction of incident AKI after acute brain injury: 166 admission-to-now features
recomputed at six-hour checkpoints, one class-weighted LightGBM per endpoint (any AKI,
>=Stage 1 primary; severe AKI, >=Stage 3 secondary), logistic recalibration layer for the
any-AKI output, applied without refitting to MIMIC-IV and eICU-CRD.

The analysis scripts in analysis/ are byte-identical copies of the scripts that produced
every reported value (subject-level 80/20 split, seed 42; selection, calibration and
deployment definitions frozen as described in the manuscript):

| Script | Purpose |
|---|---|
| analysis/f4_jinhu_extract.py | JinhuaNSICU cohort, laboratory, vital-sign and treatment extraction; unit conversions |
| analysis/f5_jinhu_features.py | creatinine event axis, six-hour grid (24 h to min(LOS - 6, 168) h), rolling features |
| analysis/f10_jinhu_dev.py | subject-level 80/20 split, labels, re-selection of 166 features from 280 candidates, LightGBM, recalibration layer |
| analysis/f11_jinhu_full_eval.py | full evaluation, calibration deciles, decision curves, external application |
| analysis/f12_jinhua_full_suite.py | two-endpoint suite: discrimination, paired differences, calibration, deployment (definition version 2), hospitals, subgroups, SHAP |
| analysis/f13_posthoc_supplement.py | post hoc supplement on the frozen f12 prediction files |
| analysis/f14_gap_fill.py | funnel counts, near-miss creatinine, development-protocol severe-AKI recalibration layer |
| analysis/f16_table1_gap_fill.py | Table 1 demographic gap fill |
| analysis/f27_m4_subgroups_mk.py | MIMIC-IV subgroups and 24-hour-stratum trend (frozen f12 predictions; ICD-coded covariates) |
| analysis/figures_r11_pipeline.py | figure pipeline (all main and supplementary figures) |
| analysis/numbers_r11_ledger.py | number ledger: every manuscript number traced to its result file |

Model objects are retrained with fixed seed 42 inside the scripts (they are not shipped);
the frozen prediction files that reproduce every reported value are regenerated by the same runs.

## Online calculator (Paper 2 model)

calculator_p2/ contains the bedside demonstration app for the JinhuaNSICU-developed model
(any-AKI and severe-AKI outputs, creatinine-only inputs, no GCS or urine output) and its
exported model artifacts (retrained under the frozen protocol; internal AUROC 0.815,
external 0.769 / 0.777 reproduced at export time).

## Databases

JinhuaNSICU (Sci Data 2025), MIMIC-IV v3.1 (PhysioNet), eICU-CRD v2.0 (PhysioNet);
access requires credentialed/database agreements.
