# Analysis scripts — rolling AKI prediction after acute brain injury (ABI)

Command-line reproduction scripts for the study *"Rolling prediction of acute kidney injury after
acute brain injury: full-KDIGO endpoint, zero-touch validation across 180 hospitals."*

These are the analysis-stage scripts (the `n*` extraction/training series and the `g*`
evaluation series) exactly as they were run to produce the manuscript's numbers, tables and
figures. The Streamlit deployment package lives in the repository root; this folder is the
research counterpart.

## Running these scripts

**They are not runnable as-is on another machine.** Every script hard-codes absolute paths to
the author's local filesystem, because that is how they were executed. Before running:

1. **Point the data paths at your own checkout.** Each script declares its results directory on
   a single line near the top:

   ```python
   R = "E:/TBI subtype/09_tbi_aki/results"
   ```

   Change that line (and any `E:/TBI subtype/data/...` literals, which refer to the raw
   MIMIC-IV / eICU-CRD downloads) to your local paths. 30 of the 31 scripts use this exact
   `R = ...` form; search for `E:/` to find every literal.

2. **The gate precondition.** Scripts call a preflight gate on their first executable lines:

   ```python
   from gate import gate
   gate(__file__)
   ```

   `gate.py` is included here. The gate is a locally-developed safety check that refuses to
   start unless a fresh `.gate_passed` marker exists in the script's directory (30-minute TTL),
   so that long analyses cannot be launched accidentally. Either run the corresponding
   `preflight_*.py` script first, or call `pass_gate()` to write the marker.

3. **Data prerequisites.** Raw data are not redistributable; obtain them from PhysioNet under
   the required training and data use agreements:

   - MIMIC-IV v3.1 — https://doi.org/10.13026/kpb9-mt58
   - eICU-CRD v2.0 — https://doi.org/10.13026/C2WM1R

   By default MIMIC-IV must be extracted as CSV (`.csv.gz`) with the standard
   `hosp/` and `icu/` layout. The `n1`–`n5` and `n8_1`–`n8_4` scripts build the feature
   matrices; the `g*` scripts consume those matrices.

4. Python 3 with pandas, numpy, scikit-learn, LightGBM, scipy and pyarrow; the deep-learning
   benchmarks (`n7_*`, `g11_*`) additionally need PyTorch.

## Script series

| Series | Purpose |
|---|---|
| `n3_*`, `n5_*` | Event grid and rolling feature construction |
| `n6_gbm.py` | Primary model: LightGBM, 291 features, temporal split (train 2008–17 / select 2018–19 / internal validation 2020–22) |
| `n7_*` | Deep-learning benchmarks (masked CNN / LSTM-attention / mini-Transformer) |
| `n8_1`–`n8_4` | eICU-CRD external cohort: crosswalk, grid, features |
| `n8_5_*` | Zero-touch external application of the frozen model |
| `g1`–`g7` | Calibration, decision curves, deployment metrics, SHAP, robustness, learning curve, comparator, Table 1 |
| `g9`–`g18` | Event-subtype stratification, EPPP calibers, deep-learning seeds, subject bootstrap, 65-year fairness cut, no-urine-output ablation, horizon visibility, hospital bootstrap, KDIGO-rule baseline, reference renumbering |

## Provenance and known cosmetics

- Scripts are published **as executed**, to keep the audit trail from code to manuscript number
  intact. They carry Chinese-language comments and non-ASCII strings; that is intentional.
- Absolute local paths (above) and the `gate` precondition are the only two things that block a
  clean re-run elsewhere. No credentials, tokens or keys are present in this folder.
- The results these scripts produced are the values reported in the manuscript; the raw JSON
  outputs are not duplicated here (they are large and are regenerated by re-running the
  scripts).

## Data availability

Analysis code, the frozen model artefact and the recalibration layer accompany the paper. The
online calculator is a research demonstration, not a clinical decision aid.
